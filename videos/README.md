### Hướng dẫn quay video nộp bài (Theo yêu cầu giảng viên):
1. Sử dụng phần mềm quay màn hình (OBS Studio, Windows Game Bar `Win + G`, Camtasia, hoặc Zoom).
2. Quay **Full Screen** toàn bộ quy trình demo các chức năng:
   - **Phần 1: Website Admin Backend (`http://localhost:5000`)**:
     + Upload file `TOEIC_Reading_v02.docx` thành công (100 câu).
     + Kiểm tra tính năng bắt lỗi file sai định dạng (chọn file `invalid_test.docx` để thấy hệ thống báo lỗi và rollback).
     + Xem trước cấu trúc 100 câu hỏi (Preview).
     + Chỉnh sửa câu hỏi / đoạn văn bài đọc trực quan (Edit).
   - **Phần 2: Ứng dụng Mobile Flutter (`http://localhost:8080`)**:
     + Xem danh sách đề thi và thông tin thí sinh Dương Hoàng Thái (2380602012).
     + Nhấn bắt đầu thi, kiểm tra đồng hồ đếm ngược 75 phút.
     + Trả lời các câu hỏi Part 5, Part 6, Part 7.
     + Mở Bảng câu hỏi (Question Palette) 100 câu, chuyển nhanh giữa các câu.
     + Nhấn Nộp bài, kiểm tra hộp thoại cảnh báo số câu chưa làm.
     + Xem màn hình kết quả: Điểm TOEIC Reading quy đổi thang 495, số câu Đúng/Sai/Bỏ qua, rà soát 100 đáp án.
3. Đặt file video tại thư mục này với tên: `demo_toeic_reading_2380602012.mp4`.
